# pii-masker

AI にデータを渡す前に、個人情報をプレースホルダへ置き換えるローカルツールです。
**処理はすべて手元のマシンの中で完結します。外部への通信は一切行いません。**

```
山田太郎様 (yamada@example.co.jp) 052-123-4567
        ↓  mask
[人名_1]様 ([メール_1]) [電話番号_1]
        ↓  AI に渡す → 回答をもらう
        ↓  mask restore
山田太郎様 (yamada@example.co.jp) 052-123-4567
```

## インストール

Python 3.10 以上が必要です。

```sh
git clone <このリポジトリの URL>
cd pii-masker
pip install .
```

テキスト・Markdown・CSV・JSON のマスクと GUI は、**標準ライブラリだけで動きます**。
docx / pdf も扱う場合は追加でインストールしてください。

```sh
pip install '.[files]'      # python-docx と PyMuPDF が入ります
```

### pip を使わない場合

クローンしたディレクトリの `bin/mask` をそのまま実行できます。

```sh
export PATH="$PWD/bin:$PATH"     # ~/.zshrc などに追記
mask --version
```

使う Python を固定したいときは `PII_MASKER_PYTHON` を指定してください。

```sh
PII_MASKER_PYTHON=/usr/local/bin/python3.12 mask 顧客リスト.csv
```

## 使い方

### CLI

```sh
# ファイルをマスク（顧客リスト.masked.csv が隣に出力される）
mask 顧客リスト.csv

# 複数ファイル・ディレクトリ一括
mask ./案件フォルダ

# クリップボードを直接マスク／復元（macOS の pbcopy / pbpaste を使います）
mask clip
mask unclip

# パイプで使う
pbpaste | mask | pbcopy
cat 議事録.md | mask > 議事録.masked.md

# 何が検出されるかだけ確認する（ファイルは書き換えない）
mask detect 契約書.docx

# AI の回答を元の情報に戻す
mask restore ai-answer.md
mask restore ai-answer.md --mapping ~/.pii-masker/mappings/20260918-144430-stdin.json
```

### GUI

```sh
mask gui
```

ブラウザが開きます。`127.0.0.1` のみで待ち受け、起動ごとに発行されるトークンを
持つリクエストしか受け付けません。CDN も外部フォントも使いません。

- **テキスト** — 貼り付けてマスク、結果をコピー
- **ファイル** — ドラッグ&ドロップで変換、結果をダウンロード
- **復元** — AI の回答を貼り付けて元に戻す
- **設定** — 検出項目の ON/OFF、URL と会社名の扱い、ユーザー辞書、除外ドメイン、対応表の削除

## 検出できるもの

| 項目 | 例 | 備考 |
|---|---|---|
| メール | `yamada@example.co.jp` | |
| URL・ドメイン | `https://example.co.jp/works/detail/` | **ドメインだけ**を置換し、パス（スラッグ）は残す |
| IPアドレス | `203.0.113.5` | プライベート IP（192.168.x.x 等）と localhost は残す |
| マイナンバー | `123456789012` | 「マイナンバー」「個人番号」が近くにある場合のみ |
| カード番号 | `4111 1111 1111 1111` | Luhn チェック＋「4桁区切り」または「カード」等の文脈語が必要 |
| 口座番号 | `1234567` | 「口座」「普通」等が近くにある場合のみ |
| 郵便番号 | `〒460-0008` | |
| 電話番号 | `052-123-4567` / `090-1234-5678` | 桁数を検証（10桁・11桁） |
| 住所 | `愛知県名古屋市中区栄3-15-33 いちご栄ビル5F` | 都道府県から／郵便番号の直後／住所ラベルの後 |
| 生年月日 | `昭和60年4月2日` | 「生年月日」ラベル付き、または元号表記 |
| 組織名 | `株式会社さくら不動産` `㈱さくら不動産` `さくら不動産 御中` `山田建設` | 法人格（略記含む）／「御中」／業種語から検出 |
| 人名 | `山田太郎様` `佐々木さん` `林部長` `山田太郎,`（CSV）<br>`山田 太郎 / やまだ / yamada` | 頻出姓 250 語＋敬称・肩書・ラベルの文脈<br>Slack の表示名形式は読み仮名・ローマ字ごと |
| ユーザー辞書 | 任意 | `~/.pii-masker/terms.txt` に書いた語 |

### URL はドメインだけを隠します

ページ構成は共有したいことが多いので、既定ではドメイン部分だけを置き換えます。

```
https://client-a.co.jp/works/nagoya-clinic/
        ↓
https://[ドメイン_1]/works/nagoya-clinic/
```

- **スラッグは保護されます。** `/campaign/0120-123-456/` のような数字入りのパスを
  電話番号や郵便番号として誤検出することはありません。
- **クエリ文字列は検査します。** `?email=...&tel=...` に入った値はマスクされます。
- **スキームが無くても保護されます。** `example.co.jp/track/4111111111111111/` のような
  書き方でも、パス内の数字をカード番号や電話番号として誤検出しません。
- **技術サイトは最初から除外。** MDN・GitHub・WordPress.org・Stack Overflow など
  73 ドメインは対象外です。自社ドメインは `~/.pii-masker/allow-domains.txt` に追記してください。
- スキームの無い `client-a.co.jp` 形式も検出します。`style.css` や `index.html` は
  誤検出しません（既知の TLD に限定しているため）。

URL を丸ごと隠したい場合は `--url-full` を付けます。

```sh
mask --url-full 提案書.docx      # https://[URL_1] ではなく [URL_1] になる
```

### Slack の表示名

`山田 太郎 / やまだ / yamada` のように読み仮名やローマ字を併記する形式は、
**丸ごと 1 人分**として置き換えます。漢字だけ隠してローマ字が残る、ということはありません。

同じ文書の別の場所に読み仮名やローマ字が単独で出てきた場合も同一人物として検出し、
**枝番**で関連付けます。AI から見て同じ人物だと分かるようにするためです。

```
山田 太郎 / やまだ / yamada     → [人名_1]
レビューは yamada にお願いします    → レビューは [人名_1a] にお願いします
やまだ さんが議事録               → [人名_1b] さんが議事録
```

復元はそれぞれ個別に行われるので、元の文章にそのまま戻ります。

読み仮名・ローマ字がフルネームの形式にも対応しています。

```
山田 太郎 / やまだ たろう / yamada taro
山田 太郎 / ヤマダ タロウ / Yamada Taro
佐々木 健一 / ささき / sasaki-k
```

ローマ字のフルネームを登録すると、単独の `yamada` も同じ人物として検出します。

区切りは `/` `／` `|` `｜` `・` `･`、姓名の間は半角スペース 1〜3 個・全角スペース・
タブに対応。ただし `山田さん / お疲れ様です` `鈴木 一郎 / よろしく お願いします` のような
チャットの文は巻き込みません。

### カード番号の誤検出対策

注文番号や管理番号が Luhn チェックを偶然通ってしまうため、区切りの無い連番は
同じ行に「カード」「クレジット」「VISA」等の文脈語がある場合だけ検出します。

```
注文番号 4539578763621486     → そのまま（マスクしない）
カード番号 4539578763621486   → [カード番号_1]
4539-5787-6362-1486          → [カード番号_1]（4桁区切りは文脈語なしでも検出）
```

社内文書でカード番号を扱わないなら、まるごと除外もできます。

```sh
mask --skip CARD 議事録.md
```

### 会社名の検出

次の 4 通りで拾います。

| 手がかり | 例 |
|---|---|
| 法人格 | `株式会社さくら不動産` `さくら不動産株式会社` `株式会社 さくら不動産` |
| 法人格の略記 | `（株）さくら不動産` `(株)さくら不動産` `㈱さくら不動産` `(有)さくら工務店` `さくら不動産（株）` |
| 「御中」 | `さくら不動産 御中` `グロウグループ御中` — 御中は組織にしか使わないので確度が高い |
| 業種語 | `さくら工務店` `山田設計事務所` `名古屋中央病院` `山田建設` `さくら不動産` |

業種語による推測は既定で有効です。実測では「加工食品」のような一般名詞を
たまに拾いますが、顧客名を取りこぼす方が困ると判断してこの既定にしています。
オフにするには `--no-org-guess`（GUI は設定のチェックを外す）を使います。

なお「システム開発」「当社サービス」「病院の予約システム」「不動産業界」のような
一般的な言い回しは組織名として検出しません。

**業務上の日付は残ります。** 「納品は2026年3月10日」のような日付はマスクされません
（生年月日ラベルが無いため）。すべての日付を消したい場合は `--all-dates` を付けます。

## 精度についての前提

ルールベースなので **100% ではありません。** 特に次は苦手です。

- 辞書に無い珍しい姓で、敬称も肩書もラベルも無いもの
- 都道府県から始まらず、郵便番号もラベルも無い住所
- 業種語を含まない屋号（「カフェそら」「ブックオフ」など）
- 画像内の文字（今回は未対応）
- URL のパスに含まれるローマ字の氏名（`/members/yamada-taro/` など）

**必ず `mask detect` か GUI の検出一覧で結果を確認してから AI に渡してください。**
確実に隠したい固有名詞は、ユーザー辞書に登録するのが最も確実です。

```sh
# ~/.pii-masker/terms.txt （1行1語、# でコメント）
mkdir -p ~/.pii-masker
cat >> ~/.pii-masker/terms.txt <<'EOF'
# 必ず隠したい固有名詞
社内コードネームA
取引先の通称
EOF
```

## 対応表（マッピング）の扱い

復元を可能にするため、`[人名_1] → 山田太郎` の対応表を保存します。
**ここには元の個人情報が平文で入ります。**

- 保存先: `~/.pii-masker/mappings/`（ディレクトリ 700、ファイル 600）
- 一覧: `mask mappings list`
- 中身を見る: `mask mappings show`
- 削除: `mask mappings purge` / `mask mappings purge --older-than 7`

復元が済んだら削除してください。そもそも対応表を残したくない場合は、
復元不能な伏字モードを使います。

```sh
mask --redact 顧客リスト.csv   # 山田太郎 → ●●●● 、対応表は保存しない
```

同じ値には常に同じプレースホルダが割り当てられるので、複数ファイルを一度に
処理しても「山田太郎」は全ファイルで `[人名_1]` になります。

## よく使うオプション

| オプション | 説明 |
|---|---|
| `--only NAME,EMAIL` | 指定カテゴリだけ検出する |
| `--skip ORG,URL` | 指定カテゴリを除外する（社名は残したい場合など） |
| `--redact` | 復元不能な伏字にする |
| `--all-dates` | 生年月日ラベルの無い日付もすべてマスク |
| `--url-full` | URL をドメインだけでなく全体（パス・クエリ込み）マスク |
| `--allow-domains FILE` | マスクしないドメインの一覧を指定 |
| `--no-org-guess` | 法人格の無い社名（「〜工務店」「〜不動産」）の推測をやめる |
| `--terms FILE` | 使用するユーザー辞書を指定 |
| `--no-save` | 対応表を保存しない |
| `--pdf-mode redact` | PDF をテキスト化せず、レイアウトを保ったまま黒塗り（復元不可） |
| `-o PATH` | 出力先を指定 |

カテゴリ名: `EMAIL` `URL` `IP` `MYNUMBER` `CARD` `BANK` `ZIP` `PHONE` `ADDRESS`
`BIRTH` `ORG` `NAME` `USER`

## ファイル形式

| 形式 | 挙動 |
|---|---|
| txt / md / csv / tsv / json / yaml / html / xml / ログ / ソースコード | そのまま置換して出力 |
| docx | **書式（太字・表・ヘッダフッタ）を保ったまま** 置換 |
| pdf（既定） | テキストを抽出し `.masked.txt` として出力 |
| pdf（`--pdf-mode redact`） | レイアウトを保ったまま黒塗り。復元不可。文字が画像化された PDF では効きません |

Shift_JIS / EUC-JP のファイルも読めます（出力は UTF-8）。

├── bin/mask                    起動スクリプト
├── pii_masker/
│   ├── lexicon.py              姓・都道府県・法人格などの語彙
│   ├── detectors.py            検出ルール（正規表現＋辞書）

│   ├── documents.py            txt / docx / pdf の読み書き
