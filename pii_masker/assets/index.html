pii-masker

個人情報をプレースホルダに置き換えます — 処理はすべて手元のマシンの中で完結します
ファイルをここにドロップ
または クリックして選択 — txt / md / csv / json / html / docx / pdf
AI から返ってきた文章を貼り付けると、[人名_1] のようなプレースホルダを元の情報に戻します。
既定では https://example.co.jp/works/detail/ を https://[ドメイン_1]/works/detail/ に置き換えます。 ページのスラッグはそのまま共有できます。?id=... 以降の値は検査対象です。
辞書の内容はブラウザにもディスクにも保存しません（このページを閉じると消えます）。 常用する語は ~/.pii-masker/terms.txt に書くと CLI と GUI の両方で使えます。
MDN・GitHub・WordPress.org など主要な技術サイトは最初から除外されています。 先頭に - を付けるとその除外を解除できます。 常用する設定は ~/.pii-masker/allow-domains.txt に書いてください。
対応表には元の個人情報が平文で入ります。保存先は ~/.pii-masker/mappings/（パーミッション 600）です。 復元が済んだら削除してください。
